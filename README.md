# first-experiments

Early BurkimbIA experiments on low-resource language models for Mooré.

## Contents

- `train_nllb.ipynb` — fine-tuning NLLB for translation
- `wav2vec.ipynb` — fine-tuning Wav2Vec2-BERT for Mooré speech recognition (ASR)

## Setup

Requires Python 3.12 and [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```
